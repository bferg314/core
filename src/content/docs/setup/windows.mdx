A fresh Windows box, in order. Everything here is scriptable — the goal is to
get from a clean install to working without clicking through installers.

## Update first

```powershell
winget upgrade --all --include-unknown
```

`winget` ships with Windows 11. If it's missing, install **App Installer** from
the Microsoft Store.

## Allow local scripts

Needed before a PowerShell profile or any local `.ps1` will run. From an
**Administrator** PowerShell:

```powershell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope LocalMachine
```

`RemoteSigned` runs your own scripts but requires a signature on anything
downloaded — the right balance for a workstation.

## Install the essentials

One command, no prompts. Trim this list to taste; it's the baseline.

```powershell
winget install --id Git.Git -e --accept-package-agreements --accept-source-agreements
winget install --id GitHub.cli -e
winget install --id Microsoft.PowerShell -e
winget install --id Microsoft.WindowsTerminal -e
winget install --id Microsoft.VisualStudioCode -e
winget install --id vim.vim -e
winget install --id OpenJS.NodeJS.LTS -e
winget install --id Python.Python.3.14 -e
winget install --id 7zip.7zip -e
winget install --id Mozilla.Firefox -e
```

Then the desktop layer — launcher, notes, search, and the utilities that only
matter once you're actually using the machine:

```powershell
winget install --id Flow-Launcher.Flow-Launcher -e
winget install --id voidtools.Everything -e
winget install --id ZhornSoftware.Caffeine -e
winget install --id Balena.Etcher -e
winget install --id mRemoteNG.mRemoteNG -e
winget install --id Telegram.TelegramDesktop -e
```

`-e` means exact ID match, so you don't get a surprise package with a similar
name.

What earns its place in that second list:

- **Flow Launcher** — <kbd>Alt</kbd>+<kbd>Space</kbd> to launch anything. Plugins
  for calculator, unit conversion, and web search.
- **Everything** — filename search that returns results as you type, across the
  whole disk. It indexes the NTFS journal directly, so it's instant where Windows
  Search isn't.
- **Caffeine** — keeps the machine awake without touching the power plan. Useful
  during a long build or a remote session.
- **balenaEtcher** — writes bootable USB images and verifies them afterward.
- **mRemoteNG** — one tabbed window for every RDP, SSH, and VNC session, with
  saved connections.

:::tip[Do this on the machine you're replacing]
Export what's already installed, then replay it on the new box:

```powershell
winget export -o C:\winget-packages.json
```

```powershell
winget import -i C:\winget-packages.json --accept-package-agreements
```

`import` skips anything unavailable rather than failing the whole run.
:::

## Configure git

```powershell
git config --global user.name "Bryan Ferguson"
git config --global user.email "ninjabreath@gmail.com"
git config --global init.defaultBranch main
git config --global pull.rebase true
git config --global core.autocrlf input
git config --global diff.colorMoved zebra
```

`core.autocrlf input` keeps LF endings in the repository while letting Windows
tools see what they expect on checkout.

Then set up authentication — see [SSH Keys](../howto/ssh-keys.mdx).

Log the GitHub CLI in as well. It handles its own token, separately from your SSH
key, and it's what makes `gh repo create`, `gh pr`, and `gh run` work:

```powershell
gh auth login --git-protocol ssh --hostname github.com --web
```

Pick **SSH** as the protocol so clones match the key you just set up. Check it
later with:

```powershell
gh auth status
```

## Set up a PowerShell profile

Your profile is a script that runs at every shell start. Create it if it doesn't
exist:

```powershell
if (!(Test-Path $PROFILE)) { New-Item -ItemType File -Path $PROFILE -Force }
notepad $PROFILE
```

A starting point:

```powershell title="$PROFILE"
# Bash-style navigation and listing
Set-Alias ll Get-ChildItem
Set-Alias which Get-Command
function .. { Set-Location .. }
function ... { Set-Location ..\.. }

# Git shortcuts
function gs { git status }
function gd { git diff }
function gl { git log --oneline --graph --decorate -20 }

# Jump to the code directory
function repo { Set-Location "$env:USERPROFILE\git" }

# Better history search: type a prefix, press Up
Set-PSReadLineOption -PredictionSource History
Set-PSReadLineKeyHandler -Key UpArrow -Function HistorySearchBackward
Set-PSReadLineKeyHandler -Key DownArrow -Function HistorySearchForward
```

Reload without restarting:

```powershell
. $PROFILE
```

:::note
`$PROFILE` differs between Windows PowerShell 5.1 and PowerShell 7 (`pwsh`).
Setting one does not affect the other. Run `echo $PROFILE` in whichever shell
you actually use.
:::

## Install WSL

```powershell
wsl --install
```

That enables the required features and installs Ubuntu. Reboot when asked, then
set a username and password at first launch.

Useful follow-ups:

```powershell
wsl --list --online          # other distros available
wsl --install -d Debian      # install a specific one
wsl --set-default Ubuntu     # pick the default
wsl --shutdown               # restart the VM after config changes
```

Cap WSL's memory and CPU use, which otherwise grows to half your RAM:

```ini title="%USERPROFILE%\.wslconfig"
[wsl2]
memory=8GB
processors=4
swap=2GB
localhostForwarding=true
```

Run `wsl --shutdown` for that to take effect.

Once inside the distro, follow [the Linux runbook](linux.mdx) — the package and
shell sections apply unchanged.

## Windows Terminal

Settings live in a JSON file you can version-control. Open it with
<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>,</kbd>. The settings worth changing
immediately:

```json
{
	"defaultProfile": "{574e775e-4f2a-5b96-ac1e-a2962a402336}",
	"copyOnSelect": true,
	"profiles": {
		"defaults": {
			"font": { "face": "Cascadia Code", "size": 11 },
			"scrollbarState": "hidden"
		}
	}
}
```

Set `defaultProfile` to the PowerShell 7 GUID listed in your own file rather
than copying that one.

## Sensible system defaults

Show file extensions and hidden files — the two defaults that cause real
problems:

```powershell
Set-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced' -Name HideFileExt -Value 0
Set-ItemProperty -Path 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced' -Name Hidden -Value 1
Stop-Process -Name explorer -Force
```

Explorer restarts on its own; the taskbar flickering once is expected.

Set the machine name:

```powershell
Rename-Computer -NewName "desktop" -Restart
```

Turn on Developer Mode, which allows symlinks without elevation:

```powershell
Set-ItemProperty -Path 'HKLM:\SOFTWARE\Microsoft\Windows\CurrentVersion\AppModelUnlock' -Name AllowDevelopmentWithoutDevLicense -Value 1
```

Dark mode, without opening Settings — works on Windows Server too, where the
personalization pages are absent:

```powershell
$themes = 'HKCU:\SOFTWARE\Microsoft\Windows\CurrentVersion\Themes\Personalize'
New-ItemProperty -Path $themes -Name SystemUsesLightTheme -Value 0 -Type DWord -Force
New-ItemProperty -Path $themes -Name AppsUseLightTheme -Value 0 -Type DWord -Force
```

Bring back the full Windows 10 right-click menu, instead of the truncated Windows
11 one with "Show more options" at the bottom:

```powershell
New-Item -Path 'HKCU:\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32' -Force | Out-Null
Set-ItemProperty -Path 'HKCU:\Software\Classes\CLSID\{86ca1aa0-34aa-4e8b-a509-50c905bae2a2}\InprocServer32' -Name '(Default)' -Value '' -Type String
```

Clear desktop — hide the Recycle Bin and the "Learn about this picture" spotlight
icon:

```powershell
$icons = 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Explorer\HideDesktopIcons\NewStartPanel'
New-Item -Path $icons -Force | Out-Null
Set-ItemProperty -Path $icons -Name '{645FF040-5081-101B-9F08-00AA002F954E}' -Value 1 -Type DWord
Set-ItemProperty -Path $icons -Name '{2cc5ca98-6485-489a-920e-b3e88a6ccce3}' -Value 1 -Type DWord
```

Those two GUIDs are the Recycle Bin and the spotlight icon respectively. `1` hides,
`0` shows — set them back to `0` to reverse either one.

Most of these need Explorer restarted before they take effect:

```powershell
Stop-Process -Name explorer -Force
```

## Check what's slowing down boot

```powershell
Get-CimInstance Win32_StartupCommand | Select-Object Name, Command, Location | Format-Table -AutoSize
```

## Verify

<Steps>

1. `git --version`, `node --version`, `python --version` all respond.

2. `ssh -T git@github.com` authenticates, and `gh auth status` shows you logged in.

3. `wsl -l -v` shows a distro in state `Running` or `Stopped`.

4. A new terminal loads your profile — `gs` in a repo runs `git status`.

</Steps>
