### Windows: stop opening the Microsoft Store

```powershell
uv run --python 3.14 python --version
```

Use `uv run` to select the managed interpreter. If typing bare `python` or
`python3` opens the Store, Windows is running an **App Installer shortcut**.

1. Open Start and search for **Manage app execution aliases**.
2. Find the **App Installer** entries for `python.exe` and `python3.exe`.
3. Switch both **Off**, then reopen your terminal.

On Windows 11, the same page is under **Settings ? Apps ? Advanced app settings
? App execution aliases**. Keep aliases for an installed Python or Python
install manager enabled. Disabling the Store shortcut does not install Python
or add it to PATH; the examples below use `uv run`.
[Microsoft documents this Store shortcut](https://learn.microsoft.com/en-us/windows/python/beginners#why-does-running-pythonexe-open-the-microsoft-store).

## Play a couple of terminal games

```sh
uv tool install --python 3.14 terminal-games
```

```sh
terminal-games
```

[Terminal Games](https://github.com/ayu5h-raj/terminal-games) runs on macOS,
Linux, and Windows with Python 3.12+. Use a terminal at least 80×24; Windows
Terminal is a good choice on Windows. Arrows navigate the menu, Enter selects,
and `q` quits.

Start with these two:

| Game | Why play it | Keys |
| --- | --- | --- |
| Snake | A quick arcade break: eat food and keep growing without hitting yourself or a wall. | Arrows or WASD steer; `p` pauses; `q` returns to the menu. |
| Minesweeper | A slower logic puzzle with three difficulty levels. | Arrows or WASD move; Space reveals; `f` flags; `r` restarts; `q` returns to the menu. |

The same collection includes Tetris, 2048, and word games. uv installs the
application's dependencies in an isolated environment; no repository clone is needed.
If `terminal-games` is not found, run `uv tool update-shell` and reopen your
terminal. See [uv's tools guide](https://docs.astral.sh/uv/guides/tools/).

## Run two small scripts

### Create a project and virtual environment

```sh
uv init --bare --no-package --python 3.14 python-starter
cd python-starter
uv python pin 3.14
uv sync
```

`uv init --bare --no-package` creates a minimal script project with
`pyproject.toml`. `uv python pin` records Python 3.14 in `.python-version`. `uv sync`
creates `.venv` and `uv.lock`; `uv run` keeps the environment in sync when
running commands. No shell activation is needed.

```sh
uv run python -c "import sys; print(sys.executable)"
```

The path should point inside `python-starter/.venv`. Keep your scripts outside
`.venv`, and exclude that directory from Git. Commit `.python-version`, `pyproject.toml`, and
`uv.lock` so another machine can install the same dependencies with
`uv sync --locked`. See [uv's project guide](https://docs.astral.sh/uv/guides/projects/).

### Hello, world

Create this file in your editor:

```python title="hello.py"
print("Hello, Python!")
```

```sh
uv run python hello.py
```

Prints `Hello, Python!`. Python runs the script through its interpreter;
there is no separate build command.

### A greeting with an argument

Replace `hello.py` with:

```python title="hello.py"
import sys


def main():
    name = sys.argv[1] if len(sys.argv) > 1 else "world"
    print(f"Hello, {name}!")


if __name__ == "__main__":
    main()
```

```sh
uv run python hello.py Bryan
```

Prints `Hello, Bryan!`; without an argument it greets `world`. `sys.argv[0]`
is the script name. The length check avoids accessing a missing argument.
`f"...{name}..."` inserts the variable into a string. Indentation defines blocks;
use four spaces. The `__main__` guard runs `main()` when the file is executed,
while allowing it to be imported without running the greeting.

## Basics worth keeping

```sh
uv add rich
```

Adds the library to `pyproject.toml`, updates `uv.lock`, and installs it into
this project's environment. Run these commands from `python-starter`.

```sh
uv run python -c "from rich import print; print('[bold cyan]Hello, Python![/bold cyan]')"
```

[Rich](https://github.com/Textualize/rich) adds formatted terminal output.
Use `uv add` for project libraries and `uv tool install` for CLI applications.

```sh
uv tool install ruff
```

```sh
ruff format hello.py
ruff check hello.py
```

[Ruff](https://docs.astral.sh/ruff/) formats code and finds common mistakes.
If `ruff` is not found, run `uv tool update-shell` and reopen your terminal.

| Command or concept | Remember |
| --- | --- |
| `uv run python` | Open the project's interactive interpreter; `exit()` leaves it. |
| `uv run python hello.py` | Run a script in the project environment. |
| `uv add rich` | Record and install a project dependency. |
| `uv remove rich` | Remove a project dependency and update the lockfile. |
| `uv tool install ruff` | Install a CLI application with isolated dependencies. |
| `uvx ruff check hello.py` | Run a tool without installing its command on PATH. |
| `uv sync --locked` | Install from the lockfile; fail if it needs updating. |

## Keep Python and your tools current

<Tabs syncKey="os">
  <TabItem label="macOS">
    ```bash
    brew update
    brew upgrade uv
    ```
  </TabItem>
  <TabItem label="Linux">
    ```bash
    uv self update
    ```

    For the standalone installer used above. If you installed uv with a
    package manager, update it through that manager instead.
  </TabItem>
  <TabItem label="Windows">
    ```powershell
    winget upgrade --id astral-sh.uv --exact --source winget
    ```
  </TabItem>
</Tabs>

```sh
uv python upgrade 3.14
```

Updates uv-managed Python within the 3.14 release family. See the
[Python upgrade guide](https://docs.astral.sh/uv/guides/install-python/#upgrading-python-versions).

```sh
uv tool upgrade terminal-games
```

Updates the game collection. To update every installed uv tool:

```sh
uv tool upgrade --all
```

From the project directory, update Rich within its declared version constraints:

```sh
uv lock --upgrade-package rich
uv sync
```

Review and commit the updated `uv.lock`. To upgrade all project dependencies,
use `uv lock --upgrade` followed by `uv sync`. See
[dependency management](https://docs.astral.sh/uv/concepts/projects/dependencies/).
Python, uv tools, and project libraries have separate update commands.
